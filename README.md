# Sentiment-Analysis-using-RNN
This project uses a Recurrent Neural Network (RNN) to classify text into positive or negative sentiment. It demonstrates the complete deep learning workflow, including data preprocessing, model training, and evaluation.
•	Developed a Recurrent Neural Network (RNN) using PyTorch to classify text as positive or negative sentiment. 

•	Processed text data by cleaning, converting it into numerical features, and splitting it into training and testing datasets.

•	Evaluated the model using classification accuracy after training with the Adam optimizer and Binary Cross-Entropy Loss.
